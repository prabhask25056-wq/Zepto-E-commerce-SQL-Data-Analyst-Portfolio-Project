# 🛒 Zepto E-commerce SQL Data Analysis

An end-to-end SQL data analytics project focused on analyzing Zepto's e-commerce inventory dataset using PostgreSQL. This project explores product pricing, discount patterns, inventory availability, and category-level performance to derive actionable business insights.

## 📌 Project Overview

This project simulates a real-world data analyst workflow, transforming raw e-commerce inventory data into meaningful insights using SQL.

The primary objective is to understand product performance, identify pricing trends, analyze inventory availability, and support data-driven business decisions in the quick-commerce industry.

## 🎯 Project Objectives

- Perform exploratory data analysis (EDA) on e-commerce inventory data.
- Identify missing values, duplicate records, and pricing inconsistencies.
- Analyze product discounts, inventory levels, and stock availability.
- Calculate estimated inventory revenue across product categories.
- Generate actionable insights to support business and inventory management decisions.

## 🔍 Key Analysis Areas

### 1. Data Exploration
- Examined the dataset structure and product records.
- Identified distinct product categories.
- Analyzed product availability and out-of-stock inventory.
- Investigated repeated product names across different SKUs.

### 2. Data Cleaning
- Checked for missing and inconsistent values.
- Identified invalid pricing records.
- Standardized pricing values for meaningful analysis.

### 3. Business Analysis
- Identified products offering the highest discounts.
- Analyzed high-priced products that were out of stock.
- Estimated potential revenue by product category.
- Compared product pricing and discount percentages.
- Evaluated average discounts across categories.
- Calculated price per gram to compare product value.
- Classified products based on weight.
- Analyzed total inventory weight by category.

## 💡 Business Insights

The analysis helps answer important business questions:

- Which products offer the highest discounts?
- Which high-value products are currently unavailable?
- Which product categories have the highest estimated inventory revenue?
- Which categories provide the highest average discounts?
- Which products offer better value based on price per gram?
- How is inventory distributed across product categories?

## ⚙️ How to Run the Project

1. Clone this repository:

```bash
git clone https://github.com/prabhask25056-wq/Zepto-E-commerce-SQL-Data-Analyst-Portfolio-Project.git
```

2. Open PostgreSQL using pgAdmin or another PostgreSQL client.

3. Create a database for the project.

4. Import the `zepto_v2.csv` dataset into your database.

5. Open `Zepto_SQL_data_analysis.sql` and execute the queries in sequence.

6. Review the query outputs to explore product pricing, discounts, inventory availability, and category-level insights.
